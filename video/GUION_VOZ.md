# Guion para grabar la voz

Graba cada línea en un archivo separado con el nombre indicado (mp3, wav, m4a u ogg),
guárdalos en `public/audio/voz-propia/` y ejecuta: `npm run voice && npm run music && npm run render`.
El video se ajusta solo a la duración de cada grabación.
